This module extends the functionality of delivery carriers in Odoo to support integration with CDEK delivery service and allows users to ship parcels through CDEK delivery service with full API integration. The module provides automatic calculation of delivery costs based on package dimensions and weight, supports various delivery methods (door-to-door, door-to-office, office-to-office, terminal, postbox) and allows creating, tracking, and canceling shipments directly from Odoo.

### Features

- **Full API integration** — Integration with CDEK delivery via API
- **Automatic cost calculation** — Delivery cost by package dimensions and weight
- **Delivery methods** — Door-to-door, door-to-office, office-to-office, terminal, postbox
- **Shipment lifecycle** — Creating, tracking and canceling shipments from Odoo
- **Tariffs and tariff types** — CDEK tariffs and types, e-commerce and standard delivery
- **Partner delivery preferences** — Per-partner settings: office codes and delivery types
- **Additional CDEK services** — Insurance, packaging, notifications and others when placing orders
- **Online tracking** — Tracking via CDEK tracking system
- **Transport waybills** — Generation of transport waybills
