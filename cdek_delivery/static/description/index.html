CDEK Delivery

This module extends the functionality of delivery carriers in Odoo to support integration with CDEK delivery service and allows users to ship parcels through CDEK delivery service with full API integration. The module provides automatic calculation of delivery costs based on package dimensions and weight, supports various delivery methods (door-to-door, door-to-office, office-to-office, terminal, postbox) and allows creating, tracking, and canceling shipments directly from Odoo.

Features

  • Full API integration — Integration with CDEK delivery via API
  • Automatic cost calculation — Delivery cost by package dimensions and weight
  • Delivery methods — Door-to-door, door-to-office, office-to-office, terminal, postbox
  • Shipment lifecycle — Creating, tracking and canceling shipments from Odoo
  • Tariffs and tariff types — CDEK tariffs and types, e-commerce and standard delivery
  • Partner delivery preferences — Per-partner settings: office codes and delivery types
  • Additional CDEK services — Insurance, packaging, notifications and others when placing orders
  • Online tracking — Tracking via CDEK tracking system
  • Transport waybills — Generation of transport waybills
If you want additional features, please get in touch with the XXP team, or you are welcome to contribute

Installation

Prerequisites

The module depends on the following Odoo modules:

  • delivery (base delivery module)

Installation of Python CDEK Library

Mention the library can be installed with command “pip install cdek” you can check the library https://pypi.org/project/cdek/

Configuration

Obtain CDEK API Credentials

  1. Register in the CDEK personal account: https://www.cdek.ru/
  2. Obtain API credentials (Client ID and Client Secret)
  3. Save these credentials for later configuration

Configure CDEK Carrier

Step 1: Accessing Delivery Settings

  1. Go to Inventory > Configuration > Shipping Methods
  2. Find the carrier “CDEK Delivery”

Step 2: Basic Configuration

  1. Open the CDEK carrier form
  2. Make sure the Provider field is set to “CDEK”
  3. Make sure the Delivery Product field is set to “CDEK Delivery”

Step 3: CDEK Configuration

Go to the CDEK Configuration tab and fill in the following parameters:

API Credentials (for production environment)

  1. Activate Production Environment mode using the smart button in the upper-right corner of the carrier form
  2. Enter CDEK Client ID — client identifier from CDEK
  3. Enter CDEK Client Secret — client secret key from CDEK
Important: If Production Environment mode is not activated, test credentials will be used.

Loading Tariffs

  1. Click the Load Tariffs button next to the Available Tariffs field
    • This will load all available tariffs from the CDEK API
  2. Select the required tariffs from the Available Tariffs dropdown
Important: Please consult your CDEK manager for suitable tariffs.

Step 4: Options

Configure additional parameters:

  1. Type:

    • “E-Commerce” (1) — for online stores
    • “Delivery” (2) — for standard delivery

  2. Print Type:

    Used for uploading printed documents for order fulfillment.

    Important: This functionality will be available in PRO version*

    • “Waybill” — waybill printing
    • “Barcode” — barcode printing

  3. Default Delivery Type:

    • “Door” — shipment from warehouse/office
    • “Office” — shipment from CDEK pickup point
    • “Terminal” — shipment from CDEK terminal

Step 5: Configure Warehouse or Recipient Address for CDEK Delivery

  1. Go to Inventory > Configuration > Warehouses
  2. Select a warehouse record and open the address partner record

Configure Partner record for CDEK

  1. Go to the partner record

  2. Open the Sales & Purchases tab > CDEK section

  3. Specify Delivery Type

  4. If Delivery Type is “Door”, fill in the required contact information:

    • City — city
    • Street — street and address
    • Country — country
    • Zip (optional) — postal code
    • Phone — phone number

  5. If Delivery Type is “Office/Postbox”:

    • Click the Search Office button

    In the wizard:

    • Fill in the required fields
    • Click the Load/Reload button
    • Click the Select button for the selected record

  1. Select the delivery tariff from Tariff
  2. Contragent Type is automatically determined based on partner type (company/individual):
    • “Legal Entity” — legal entity
    • “Individual” — individual

Manage CDEK Services

Note: Most services are already pre-configured, so you generally don’t need to configure them unless CDEK has updated the list.
  1. Go to Products > Products (remember to clear any preset filters)
  2. Create a new product or open an existing one
  3. Set product type as Service
  4. Select CDEK Reference from available services
  5. When selecting a CDEK service reference:
    • The product is automatically configured as a service (not for sale/purchase)
    • The CDEK service code is copied to the Internal Reference field

Configure Packages

Note: Enable Packages in Settings > Inventory > Operations.

  1. Go to Inventory > Configuration > Package Types
  2. Select a record or create a new one
  3. Configure the box dimensions, and min/max weight
  4. Specify the carrier (optional)

Usage

Sale Flow with CDEK delivery

Important: Make sure you have configured the partner for CDEK delivery.

Create Sale Order

  • Go to the Sales app
  • Click the “+New” button to create a quotation
  • Select a partner in the “Customer” field
  • Add a product to sell
  • Click the “Add Shipping” button

Get Shipping Rate

  • On the Add a shipping method wizard:
    • Select CDEK Delivery in the “Shipping method” field
    • Select a package type
    • Add a CDEK Additional Delivery service and the required service value
      • For packages — quantity (integer > 0)
      • For insurance — insurance value (positive number)
      • For SMS — phone number in format +7XXXXXXXXXX
      • For packaging materials — length in meters
  • Click the “Get Rate” button
  • The service cost will be set automatically
  • Press the “Add” button to add the CDEK Delivery product to the sale order

Delivery Cost Calculation

When calculating delivery cost, the following are taken into account:

  • Selected CDEK tariff
  • Package dimensions and weight
  • Selected additional CDEK services
  • Delivery type (door/office/terminal/postbox)
  • Once the sale order is confirmed, Odoo will create a delivery operation

Register the package

  • Go to the created picking operation
  • Validate the picking
  • Odoo will register the package with the CDEK carrier
  • Go to the “Additional Info” tab
  • Check the CDEK Order UUID and tracking reference

To Cancel the Order

  • Go to Inventory > Your Delivery Operations
  • Open a picking to cancel the CDEK Delivery
  • Go to the “Additional Info” tab
  • Press the “Cancel” button
