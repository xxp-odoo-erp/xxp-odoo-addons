This module extends the EE Barcode App features:

- Switch the company environment in the Barcode App
- Show the current company in the picking list

Use Cases / Context
===================

We need an opportunity to serve different companies in a single
warehouse. So we need to switch companies right in the Barcode App. 

Configuration
=============

No special configuration required. Set the Allowed Companies in the user
settings to grant user access.

Usage
=====

To switch the company environment
---------------------------------

- Go to the Barcode App
- Click on the button with the current company name
- On the drop-down list, select a company
