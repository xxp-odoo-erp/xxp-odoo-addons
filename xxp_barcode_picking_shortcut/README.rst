This module:

- Moves the helper text on the main Barcode app screen into a tooltip
- Adds shortcut buttons for the selected operations on the main Barcode
  app screen
- Lets the user set the order of those shortcut buttons

Use Cases / Context
===================

Warehouse operations are sometimes performed in a rush. To open the most
recent operations, the user has to carry a printed barcode. This module
removes the need to scan the operation barcode or to search for the
operation in the operations list.

Configuration
=============

To configure the Barcode App operation shortcut:
------------------------------------------------

- Go to the **Inventory -> Configuration -> Operation Types**
- Select the operation record
- Go to the "Barcode App" tab
- Enable the "Barcode App Shortcut" checkbox
- Set the "Barcode App Shortcut Sequence" number to reorder the
  shortcuts

Usage
=====

- Go to the Barcode App
- The operation with the enabled "Barcode App Shortcut" will be visible
  on the main screen
